# Dataset and attribution

**Online Retail II**, Daqing Chen, UCI Machine Learning Repository, DOI https://doi.org/10.24432/C5CG6D. Download page: https://archive.ics.uci.edu/dataset/502/online+retail+ii. Licence listed by UCI: CC BY 4.0.

The repository includes the original `online_retail_II.xlsx`, extracted unmodified from the user-uploaded official UCI dataset archive. Two source sheets cover December 2009–December 2011. The file has 1,067,371 transaction rows. All figures and risk labels are derived analytical outputs rather than attributes supplied by UCI.
